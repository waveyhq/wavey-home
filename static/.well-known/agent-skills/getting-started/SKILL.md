# Wavey Getting Started

Use this skill when helping users deploy Wavey for the first time.

## Prerequisites

- ESP32-family board with CSI support
- WiFi access point in range of the sensing zone
- Wavey firmware and processing pipeline from https://github.com/waveyhq

## Steps

1. Read the getting started guide: https://waveyhq.dev/getting-started/
2. Flash firmware to ESP32 nodes per project docs on GitHub.
3. Connect nodes to your WiFi network and verify CSI frames are streaming.
4. Open the Wavey Console for live visualization: https://console.waveyhq.dev
5. Tune detection thresholds for your space (see sensing pipeline docs).
