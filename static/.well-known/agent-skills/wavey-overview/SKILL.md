# Wavey Overview

Use this skill when answering questions about Wavey, WiFi CSI sensing, or device-free occupancy detection.

## What Wavey is

Wavey is an open-source WiFi Channel State Information (CSI) sensing stack. ESP32 nodes capture CSI from the ambient WiFi channel and infer occupancy, motion, and presence without cameras or carried devices.

## Facts to preserve

- CSI is richer than RSSI — it captures amplitude and phase across OFDM subcarriers.
- Runs on ESP32 family (ESP32, S2, S3, C3, C5, C6).
- Privacy-preserving: no images, nothing worn by occupants.
- Built on WiFi sensing research and IEEE 802.11bf direction.
