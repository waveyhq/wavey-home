Wavey is an open-source WiFi CSI sensing stack: ESP32 nodes capture Channel State Information from the ambient WiFi channel, and a Python pipeline processes it in real time.

The output is occupancy, motion, and presence inference for a space—without turning the room into a camera network or asking people to carry a device.

What is WiFi CSI sensing?

Channel State Information (CSI) is how a WiFi link measures the channel between transmitter and receiver: amplitude, phase, and delay across many OFDM subcarriers. A single RSSI reading collapses that into one number; CSI keeps the detail.

Walls, furniture, and bodies all reflect and absorb radio energy. When someone moves—or stays still enough that breathing shifts the field—the subcarrier pattern shifts in consistent ways. Sensing systems read those shifts to infer what changed in the environment.

Use cases

  • Device-free occupancy detection
  • Motion & activity detection
  • Presence & breathing detection
  • Elder-care & fall-aware monitoring
  • Security & intrusion detection
  • Smart-home automation
  • Occupancy analytics

Built for developers and self-hosters

A typical deployment has three layers: ESP32 sensing nodes capture CSI from WiFi; a host runs the Python pipeline (ingest, clean, featurize, infer against a baseline); results stream to the Wavey Console for live visualization and can feed automations or analytics.
